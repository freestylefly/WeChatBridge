    关于鉴权

    登录走微信开放平台网站应用扫码（POST /v1/auth/session → 二维码 → 轮询 → 双令牌）， 管理操作携带 Authorization: Bearer。访问令牌只存 sessionStorage， 关闭标签页即失效；卖家微信的管理员身份由服务端 OpenID 白名单判定。
