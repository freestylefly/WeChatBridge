# Windows 兼容层（TransferTargetShim）

微信流 Windows 版提示「系统低于 24H2」时，可以安装兼容层，让微信「转发到其他应用」里出现微信流。

兼容层的安装包（`Install-CompatLayer.cmd` 等）和安装说明统一放在下面的飞书页面，会随版本更新：

👉 **[获取兼容层下载与安装说明](https://my.feishu.cn/wiki/Eq6twbgv5irYgikOa8Pc2fHfnKg#share-RNMedgl3VoT0M5xZRNVcCXPBnSe)**

安装中遇到问题，欢迎在 [Issues](https://github.com/freestylefly/WeChatBridge/issues) 反馈，附上系统版本（`winver`）和微信版本。

## Windows compatibility layer (TransferTargetShim)

If WeChatBridge for Windows reports that your system is older than 24H2, install the compatibility layer so WeChatBridge appears in WeChat's "Forward to other apps" list.

The installer (`Install-CompatLayer.cmd` and related files) and setup instructions are hosted on this Feishu page and kept up to date:

👉 **[Download the compatibility layer and setup guide](https://my.feishu.cn/wiki/Eq6twbgv5irYgikOa8Pc2fHfnKg#share-RNMedgl3VoT0M5xZRNVcCXPBnSe)**

If something goes wrong, open an [issue](https://github.com/freestylefly/WeChatBridge/issues) with your Windows version (`winver`) and WeChat version.
