# Windows 分批收集浮窗改版

## 信息与操作

默认是一张 400 px 的收集卡片，兼容 320 px。顺序为收集状态、批数/估算消息数/大小、最近一批的会话与时间范围、下一步提示。保留拖动和隐藏，隐藏不结束收集。

底部只有「查看 N 批」和「选择去向…」。会话名称是可选备注，未填写也能选择去向并交付原始文件。没有自动发送行为。

详情打开独立窗口，浮条保持紧凑。五批以内用带选中态的批次切换按钮，更多批次用下拉框。默认呈现选中批次的首条、末条，其余参考折叠在「更多定位参考」中；短批次的重复参考只显示一次。详情共享一个滚动区域，底部操作保持可见。

## 编辑与文件操作

「会话备注」展开编辑框，明确保存或取消。Enter 保存，Escape 取消编辑；非编辑状态的 Escape 关闭详情窗口，保留收集。识别微信只填入候选名称，确认保存后才写入记录。编辑期间仍能选择去向：已填写的备注提交保存，空白备注不阻断流程。

「查看原始文件」定位选中批次。「移出本次收集」和「删除（可撤销）」放在批次操作菜单；有可撤销操作时才显示撤销按钮。整组操作仍在顶部更多菜单中。

## 交付

选择去向打开独立面板，只列出已安装的应用，同时提供复制和保存文件夹。目标采用单选卡片并说明操作结果。用户再点击「附加到…」「复制…个文件」或「保存…个文件」才执行交付。取消或 Escape 保留收集。附加之后需要在目标应用确认附件，不把执行粘贴表述为完成发送。

## 验证

界面测试使用可解析聊天 ZIP，覆盖两批切换、短批次参考去重、改名取消/保存、交付与目录选择取消、保存中不提前计数、中文/英文、320 px 和放大文字预览。

## 最终主题与保存反馈

浮条、详情、去向、自绘目录和删除确认统一复用主程序 `AppTheme.xaml` 的颜色资源；不维护独立配色或单独跟随系统深色设置。

分享接收程序在保存阶段发布带心跳的临时状态，浮条显示「正在保存第 N 批…」。该状态不修改收集账本；原子提交完成后才增加已收批数。保存失败提示重新分享本批，已收批次保留。
