# 公众号正文抓取

`wechat-article-extract` 只能整理聊天记录里**已经存在**的内容；本技能补上它做不到的另一半：
拿 `mp.weixin.qq.com` 链接去抓真实正文。两者通常配合使用——前者找出链接并标出哪些
「仅有链接，未含正文」，后者把这些链接补全。

## 输入

- 一个或多个 `mp.weixin.qq.com/s/...` 链接，通常来自聊天记录导出、分享卡片或用户直接粘贴。
- 本技能自带脚本 `scripts/wechat-article.ts`，与本 `SKILL.md` 位于同一目录。

## 步骤

1. **先确认运行环境**：执行 `node --version`。
   - 需要 **Node ≥ 22.18**（或 ≥ 23.6）；脚本靠 Node 原生 type stripping 直接运行 `.ts`，
     不需要 `npm install`，也不需要浏览器。
   - 没有 Node 或版本过低时，**不要**尝试安装 Node、Homebrew、npm 包等任何外部依赖，
     直接走下面的「降级」写法并如实说明。
2. **逐篇抓取**。脚本零依赖直连 `mp.weixin.qq.com`：

   ```bash
   # 单篇：正文进上下文，同时会落盘到 -o 指定目录
   node "<本 SKILL.md 所在目录>/scripts/wechat-article.ts" "<url>" \
     -o "<临时目录>/wechat-article-fetch" --stdout --format md

   # 多篇：批量 + 顺带下载正文图片
   node "<本 SKILL.md 所在目录>/scripts/wechat-article.ts" URL1 URL2 \
     -o "<临时目录>/wechat-article-fetch" --format all --images
   ```

   - 把 `<本 SKILL.md 所在目录>` 换成运行期真实的目录，不要照抄占位符；目录或路径含空格时
     保持加引号。
   - `<临时目录>` 用系统临时目录：macOS / Linux 是 `$TMPDIR`，Windows cmd 是 `%TEMP%`，
     PowerShell 是 `$env:TEMP`。
   - **始终显式给 `-o`**，并指向临时目录：脚本无论如何都会落盘（默认会写 `./articles`），
     不指定就会污染用户的工作目录。
3. **按退出码判断结果**：`0` 全部成功 · `1` 有链接失败 · `2` 用法错误。
   进度和失败原因都写在 **stderr**，`--stdout` 的正文才在 stdout。
4. **对每篇文章提取**：标题、公众号、作者、发布时间、原文链接、正文、图片。
5. **抓取失败的链接如实标注**：保留原链接，并照抄脚本给出的失败原因——它按页面内容区分
   「触发风控验证页（环境异常）」「链接参数错误或已失效」「文章已被发布者删除」
   「文章因违规无法查看」等情况，**不要**用标题、卡片摘要或自己的猜测补正文。

## 输出

每篇文章一节，用 Markdown 输出：

```markdown
## 1. {标题}
- 公众号：{名称}
- 发布时间：{时间}
- 原文链接：{URL}
- 图片：{数量，或「无」}

{正文，或「抓取失败：{脚本给出的原因}」}
```

结尾附一个汇总表：编号、标题、公众号、抓取结果。

## 注意

- 只处理公众号文章；其他链接不算，在汇总表末尾列一行「跳过的其他链接」。
- **不绕过访问控制**：脚本遇到风控验证页、过期链接会直接报错退出。照着报错如实回答，
  不要重试到成功为止，也不要改用别的手段绕开。
- **正文结构会被压平**：标题层级、表格、代码块都不保留（实测 18 个表格 → 0、
  23 个代码块 → 0、8 个 `<h2>` → 0），`<pre>` 里的空白也会被折叠。正文和图片是完整的，
  但表格列对应关系、代码围栏和语言标记、标题级别拿不回来——需要保留结构时必须主动告诉用户。
- 图片默认保留远程 URL；只有显式加 `--images` 时才下载到 `-o` 目录下的 `images/`。
- **批量时不限速**：脚本只在失败时退避重试，不控制整体频率。批量抓取要自己放慢节奏。
- 保持原文措辞，不做改写或评价。

### 降级：环境不具备时怎么办

环境缺少 Node 或版本过低时，**不要**编造正文，按下面这一条如实输出，让用户自己决定：

```markdown
## 1. {标题}
- 公众号：{卡片或记录里的名称}
- 发布时间：{已知时间或「未标注」}
- 原文链接：{URL}
- 图片：无

本机缺少 Node ≥ 22.18，无法抓取正文；仅有链接，未含正文。
```
