# 视频信息读取

从微信聊天记录导出文件（ZIP 或已解压内容）中找出所有视频内容，整理成可检索的结构化笔记。

## 输入

- 视频可能以三种形态出现：
  1. 聊天记录里的视频平台链接（视频号、B 站、抖音、YouTube 等）；
  2. 视频号/小程序分享卡片（标题 + 来源 + 封面图）；
  3. 随记录导出的本地视频文件（mp4 等）或视频截图。

## 步骤

1. 扫描全部附件文本，找出视频链接、分享卡片和视频文件，按聊天中出现顺序编号。
2. 对每条视频提取：
   - **来源**：平台名称（视频号 / bilibili / 抖音 / 本地文件等）；
   - **标题**：卡片标题或文件名；
   - **链接或文件名**：完整 URL 或附件内文件名；
   - **可获得的信息**：附件文本中已有的简介、字幕、转写、截图文字——全部保留；
   - **关键时间点**：如果附件中含字幕或转写，标出重要话题开始的时间点；没有就写「无时间信息」。
3. 对每条视频写一段**摘要**：基于附件里实际存在的文字信息归纳；只有链接没有内容时，标注「仅有链接，无法读取内容」，不要根据标题猜测正文。

## 输出

每条视频一节，用 Markdown 输出：

```markdown
## 1. {标题}
- 来源：{平台}
- 链接/文件：{URL 或文件名}
- 时长：{已知时长或「未知」}

### 摘要
{基于附件信息的摘要，或「仅有链接，无法读取内容」}

### 关键时间点
- {mm:ss} {话题}（无则写「无时间信息」）
```

结尾附汇总表：编号、标题、来源、是否有可读内容。

## 注意

- 只处理视频；图片和普通文件不算，但在汇总表末尾列一行「跳过的其他附件」。
- 无法播放视频文件本身时，如实说明，只整理附件中已有的文字信息。
- 保留附件中原始字幕/转写的时间戳格式，不做换算。
