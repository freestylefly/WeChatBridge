# Windows 设置向导 v2

沿用主程序的绿色、白色和灰色。780×620 的稳定窗口，小屏幕下适应工作区，内容滚动且底栏固定。左侧只显示四步进度，右侧完成真实配置；不重复绘制十二个入口，不把所有应用假定为已安装。

```mermaid
flowchart LR
    A[认识微信流\n聊天记录 → 微信流 → 目标应用] --> B[选择目标\n已安装的应用才能开启\n剪贴板与分批收集直接可用]
    B --> C[启动偏好\n直接设置登录后后台运行\n与通用设置同步]
    C --> D[配置摘要\n已开启目标 + 启动状态\n分享入口真实检测结果]
    D --> E[完成设置\n去微信转发一小段记录验证]
    A --> F[未检测到 Windows 分享入口\n显示检查方法 + 重新检测]
    F --> B
```

关闭向导保存进度但不标记完成；返回可修改设置；选择入口即时保存，缺少目标应用的卡片禁用并说明原因。完成页不会把 Windows 注册状态等同于微信菜单已刷新。所有页使用一致的上一步 / 下一步底栏。

清晰度修复：不把整个内容放进带阴影的位图效果层；改用不透明窗口与原生窗口阴影。主程序和分享组件声明 PerMonitorV2，字体采用 Display 排版、像素对齐和微软雅黑 UI。

验证记录：核心与界面测试共 295 项通过，四个页面完成中英文在 100%、125%、150%、200% 下的渲染检查；新进程的 DPI awareness 实测为 2（Per Monitor），旧版本为 1（System）。真实混合 DPI 显示器间切换尚未验证。发布包版本为 1.0.3。
