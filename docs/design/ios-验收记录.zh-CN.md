## 验收中发现并修复的问题

| 现象 | 原因 | 提交 |
|---|---|---|
| 0 字节文件也被存进中转站 | 分享扩展没有检查空文件 | cfbced3 `[AI] fix: share extension rejects empty files` |
| 点卡片不进详情，只高亮 | 非编辑状态下 `List(selection:)` 吞掉了点击 | 0d48b3f |
| 引导页第 3 页的 Obsidian 按钮压住页码点 | 按钮在 Spacer 之下 | 0d48b3f |
| 场景开关打不开，投递面板只有「不带场景」 | 绑定用了只查已启用场景的 `scene(id:)` 和保留旧开关的 `replace(_:)`；导入同理 | 767fedd |
| 单组发送完成后按钮显示「继续发送第 2/1 组」 | 标题没有处理全部发完的情况 | 34e2d5a |
| 编辑模式下「合并投递 / 删除」被标签栏挡住；计数被截断 | 底部工具栏和标签栏重叠 | 34e2d5a |
| 设置页两行「微信流」看不出是什么 | 子文件夹 TextField 没有标签 | 34e2d5a |
| 投递成功后目标宫格当场重排，刚点的目标跳走 | 宫格直接读 `preferences.targets`，记录投递时最近使用的目标会排到最前 | 34e2d5a |

## 已知限制（未改）

- 一个批次里有多个 ZIP 时，卡片标题和条数取第一个能解析的 ZIP，其余 ZIP 只计入附件数（`RelaySummary.make(for:)`）。规格没有要求多 ZIP 的合并摘要；投递时多个 ZIP 会全部带上。
- 撤销窗口是 5 秒（规格值）。
