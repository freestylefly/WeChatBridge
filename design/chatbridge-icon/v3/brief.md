# 信息桥 Logo Brief（logo-design skill · 快速通道）

- **名称**：信息桥 / Chat Bridge
- **做什么**：把聊天记录、分享内容一键转交给 AI（豆包、千问、ChatGPT、Claude、Obsidian），整理成对方读得懂的格式
- **用户**：用微信沟通、用 AI 干活的中文用户；同一作者的「闪念速记」用户
- **形容词**：顺（一下就过去）、连接、可靠、轻、聪明
- **品类套路（避开）**：对话气泡（尤其双气泡 = 微信，4.1(a) 被拒原因）、微信绿、纸飞机、箭头、链条环、Wi-Fi 弧、具象桥梁图画、四角星（AI 套路）
- **约束**：iOS 分享栏 60px、设置 29px；两色平涂；和「闪念速记」（黄 + 墨、一笔粗线）是同一家族，但不能像
- **家族手法**：一笔粗线（stroke 28、圆头），交叉处压线断开

## 词汇图
信 → 人 + 言、书信、鸿雁传书、信得过
息 → 消息、气息、一口气
桥 → 鹊桥、拱、两岸、渡、搭线、牵线

## 长名单
1. 鹊桥结：一道拱，拱顶打一个小圈——把一段话系好，渡过去  ← 选
2. 「」相扣：一对中文直角引号互相扣住——两边的话接上了  ← 选
3. 一笔渡：一笔画出拱，再折回来从拱脚下穿过，成了桥面——一笔连起两岸  ← 选
4. 牵线：两个点之间一根线，中间绕一圈（太像闪念速记的结，放弃）
5. 鸿雁：一笔画出的飞鸟（海鸥图标太多，放弃）
6. 「信」字标：人 + 言（笔画多，29px 糊）
7. 吊桥：两根柱子之间一道垂弧（太具象）
8. 接力：两只钩子交叉相扣（和 2 重复，留 2）
9. 倒影：拱和水中倒影合成一只眼（读成眼睛，跑题）
10. 引号流：三个引号排成一列逐个变小（像加载动画）
11. 双 C：Chat 的 C 和反向 C 拼成桥洞（字母标，中文用户无感）
12. 渡口：半圆 + 一道水平线（像日出图标，放弃）
